# Estilo de narrativa: Romântico — v1.0.0

> Skill de runtime versionada. Melhorias vão como nova versão (v1.1.0…), preservando esta.

## Contrato
- **Entrada:** respostas do questionário (nomes, como se conheceram, momentos, piadas,
  viagens, dificuldades, planos, mensagem especial).
- **Saída:** blocos de narrativa mapeados aos elementos de layout (abertura, capítulos,
  legendas de polaroid, linha do tempo, carta final, dedicatória).

## Regras de estilo
- Tom afetivo, íntimo e sincero; primeira/segunda pessoa; frases curtas e quentes.
- Nunca inventar fatos: usar apenas o que o casal informou; se faltar dado, ser genérico
  sem afirmar algo falso.
- Português do Brasil; evitar clichê excessivo; respeitar nomes e pronomes informados.
- Comprimento por bloco compatível com o espaço do layout (ver layout-element).

## Golden samples
Mantenha em `golden-samples/` exemplos aprovados de entrada → saída, usados pelos testes
de estilo no CI para garantir que mudanças não descaracterizem o tom.
